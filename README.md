## Добавлено: 
### Многоканальное меню 
* Промежуточное меню, которое открывается при клике на кнопку виджета.
* Функционал: Пользователь может выбрать способ связи: WhatsApp, Telegram, Max или перейти в онлайн-чат.
* Конфигурация: Добавлены поля whatsapp, telegram, max в конфиг для динамической подстановки ссылок.
### 2. Анимация
* Звуковые уведомления: Добавлен звук при получении ответа от бота.
* Авто-подсказка: Кнопка виджета автоматически раскрывается с текстом «Не готовы к звонку? Напишите вопрос в чате» через 6 секунд бездействия пользователя.
### 3. Сеть (Offline/Online)
* Сохранение истории: История чата сохраняется в localStorage. При перезагрузке страницы диалог восстанавливается.
* Обработка разрывов связи: Если интернет пропал во время отправки, сообщение помечается как pending. При восстановлении сети виджет автоматически пытается отправить его снова.
Защита от дублирования: Используется счетчик activeRequestId, чтобы игнорировать ответы от старых запросов, если пользователь быстро отправил несколько сообщений подряд.
### 4. Гибкая кастомизация дизайна
* Конфигурация цветов: Клиент может менять цвет кнопки (buttonColor), цвет иконок (iconColor) и фон виджета (widgetColor) прямо в HTML-коде подключения, не залезая в CSS.
### 5. Улучшенная структура
* Экранирование HTML: Добавлена функция escapeHtml, чтобы пользователь не мог сломать верстку или внедрить скрипты через текст сообщения.
* Ленивая загрузка: Само окно чата (wrapper) создается и добавляется в DOM только в момент первого открытия.
#### Адаптивность под мобильные: Добавлены медиа-запросы для экранов <780px, <480px и <380px.
